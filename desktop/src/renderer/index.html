欢迎使用 AI 生图贴回

    
在 Photoshop 里框选一块画面，AI 生成后自动贴回原位置。三步就能用：

    
    
      
  1. 
        
    安装 Photoshop 插件
    
        
    把插件装进 Photoshop 2024（25.0）以上版本。装完重启 Photoshop，在菜单「增效工具 → AI 生图贴回」打开面板。
    
        
      
    2. 
      
  2. 
        
    登录生图账号
    
        
    网页平台不需要 API Key，用你自己的 Google / ChatGPT 账号，在专用 Chrome 里登录一次即可。
    
        
    
          
    
          
    
        
    
        
    还没有账号？购买账号 · 购买 Gemini Pro 账号
    
      
    3. 
      
  3. 
        
    开始生图
    
        
    在 Photoshop 面板里框选 → 选预设或写提示词 → 生成并贴回。也可以在桌面端「工作台」里生图、看大图、对比网页原图和贴回的版本。
    
      
    4. 
    

    
使用须知：使用无需 API 的生图服务（AI Studio、Google Flow、ChatGPT 网页）需要自备魔法，专用 Chrome 要能正常打开 Google 和 ChatGPT。

    

      之后可以点顶栏的「使用说明」再打开
