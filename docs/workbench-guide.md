# 0.7 工作台使用指南

桌面端负责选图、预设、队列、流程和结果管理，Photoshop 面板负责捕获与贴回。Google / ChatGPT 网页生成仍使用专用 Chrome；是否关闭生成标签页由设置页控制。

## 从一张照片开始

1. 在「工作台」选择原图、平台和提示词，或者选择 Photoshop 选区。
2. 自动换平台仅在兼容的网页 / CLI 通道间切换；自定义 API 和模型工作流由你明确选择。多图服务完成后，到「候选与恢复」选择需要的结果。选定之前不会自动贴回，也不会把未选图片传给下游步骤。
3. 在大图查看器切换「网页原图」「贴回版本」检查校色差异。已下载结果的回传失败只需重试贴回。
4. 修改两端共有的生成设置后会自动同步。设置页「PS 与桌面共享设置」可以查看并恢复参数历史。

## 原文档、异形选区和多区域

在「文档与分区」读取打开的 Photoshop 文档。捕获会保存文档会话、画布尺寸、区域坐标和异形选区像素。可捕获多个文档，或按块尺寸/重叠规划分区。

- **每区独立生成**：使用工作台当前设置和参考图建立暂停队列；检查数量后开始。暂停时可编辑未提交项目的提示词，或把当前预设与参数单独应用到该项。
- **拼成一张图**：把所选区域拼成一张原图，在工作台生成，再回来选择结果并拆分。比例不一致时会拒绝拆分。
- **贴回**：使用记录中的原文档和原区域。原文档关闭、重开、改变尺寸时会停止；同尺寸的新会话可以明确重绑。
- **选区与蒙版**：透明结果用 Alpha，真正的灰度结果用灰度模式，可载入选区、图层蒙版或独立通道。

## 预设与参考图

「预设管理」提供编辑、复制、历史恢复、导出与导入预检。出厂预设修改后保存个人副本。「图库与剪影」可以管理持久参考图、自定义分类和分类命中区域。图库不会因临时上传过期丢失；用于生成时仍受所选模型参考图能力限制。

未知工作流格式不会当作普通提示词静默导入。Forge 参数、ComfyUI API 工作流和 RunningHub 映射分别在对应连接工具里配置。

## 修图工具和引擎

「工具与项目」包含本地调色、示波器、独立校色/强度、双区颜色匹配、辉光、变化检查和抠像。先计算预览，再保存结果；预览与保存使用同一份图像。

变化检查显示的是差异建议，正常修改也可能被标记。只有源图尺寸与完整 PS 画布一致时才可把候选位置映射到所选文档，避免猜测裁剪位置。

语义选区与专用增强须绑定真实模型工作流及输入/输出节点。未连接、缺少节点或权重时会明确报错，不会偷偷换成普通生成或插值放大。本机抠像模型可以单独下载、检查、停止和移入可恢复回收站。

## 流程与创作幕布

「流程与分块」适合固定的连续步骤与分块生成。「创作幕布」可以连接图像、生成、候选、拼接和输出节点。保存后先审阅预计提交次数和参数，再开始。

每个服务的多输出候选与幕布的分支候选分别选择。选定的图片被固定为下游输入；暂停、重开和失败重试保留已完成步骤。已有上游 ID 的任务可查询和恢复下载，恢复不会重新提交。

相机/布光预览是近似示意。拆光生成黑底光照贡献图，可作为滤色层贴回；它不是物理测量。多页海报提供页面规格和文字字段，结果中的文字、身份和一致性需要逐页检查。

## 历史、项目和备份

「历史与恢复」支持分页、原图/项目筛选、版本预览、提示词复用及检查点恢复。恢复会生成新结果，不覆盖原文件。

「项目日程」记录状态、日期、关联文档和任务。「管理与帮助」提供布局、前台快捷键、缓存回收站、备份预检与回滚、书签、Eagle 归档以及脱敏诊断。备份包排除登录信息、密钥与浏览器配置；恢复后如提示需要重启服务，请等生成任务空闲。

## 助手与知识库

助手可用已配置的语言模型连接或本机 Codex。资料检索展示来源与行号，导入内容只作为资料。预设提案先进入收件箱，经检查后保存；修图计划绑定明确文档，每一步需要实际操作才能执行。对话说“完成”不代表 Photoshop 动作已经执行。

## 安装和验收边界

App 更新后到设置页检查 Photoshop 插件更新。磁盘插件更新完成后，正在运行的 Photoshop 可能仍加载旧代码；保存文档并重新加载插件或重启 Photoshop 后才使用新版本。

Windows 安装包和跨平台契约测试不替代 Windows 实机验收。ComfyUI、RunningHub、Forge、语言模型以及其他外部服务需要自己的可用连接和模型；本地模拟测试不代表真实账号推理或视觉效果验收。

## 存储与原生窗口

「存储与配额」可预检新目录、确认复制迁移、逐文件核验摘要，再更新配置；原目录保留。迁移后需空闲时重启服务；不要手动删除原目录，直到确认新目录可用。配额超限阻止新写入，不自动删除原图或检查点。

「管理与帮助」可打开 HTTPS 参考分屏和任务浮卡，调整主题、缩放和透明度。Google/ChatGPT 登录仍用专用 Chrome。项目提醒依赖 App 驻留和系统通知许可。备份包含图库及填空历史，排除密钥、浏览器档案和完整生成图；超过包大小限制时明确拒绝，不静默漏项。

## 旧版 Windows 自动更新失败

如果旧版下载完就退出、重开仍显示旧版本，请从 GitHub Releases 下载 Windows 安装包并手动覆盖一次。新发布内容不能反向修复已安装的旧更新器。0.7.0 起先确认安装助手就绪，再退出；助手等待旧进程结束、覆盖当前目录、核验版本并记录结果。更新失败弹窗提供已下载安装包入口；更新弹窗和设置页均提供 GitHub 下载。Windows 实际安装仍需在 Windows 上确认。
