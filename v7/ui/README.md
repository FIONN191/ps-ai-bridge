## 当前基线

`ui.html` 的 9 张卡是注册集合。`layout-core.js` 全新默认隐藏调试卡，其他 8 张可轮换，设置卡不可隐藏；已保存的用户布局另算。项目与助手旧卡及路由仍保留，Agent 常用入口是主 WebView 内独立悬浮界面，并非新增 OS 窗口。

> 最近同步：2026-09-28。项目时间线、Agent 悬浮窗、工具独立剪影和布局模拟工具已接入；真实 Photoshop、Tauri 原生窗口和生产后台仍需单独人工验收。

- 透明无边框窗口、叠压主卡、二级/三级联动、折叠药丸和统一动画已完成。
- 任务堆、L1-L4 报错体系、L4 独立冻结窗口和背景接口已完成。
- 每次运行完整链路都会重新抓取当前 Photoshop 文档/选区；任务保存 `docId`、`docName`、`selection`、图片、`antiMode`、`capturedAt`、`captureId`，生成完成后严格回传到原任务目标。
- 3K/4K 抓取显示实际像素尺寸和阶段状态；任务栏滚轮采用原地更新，缩略图滑入有外框遮罩；大图支持屏幕内适配、胶囊提示和 `Esc` 退出。
- 任务级并发不设上限：每次“运行完整链路”都创建独立任务，任务卡、来源快照、生成请求和回图互相隔离；“停止当前”只处理当前任务。
- 自动回归已覆盖快速连续创建、同毫秒任务 ID、乱序抓取/返回、单任务取消、队列与立即任务并行，当前 `tests/ai-task-concurrency.test.js` 为 4/4 通过。
- 阶段性的开发、链路验证、日志和 AI 全量验证入口已从当前 UI 移除；底层能力和测试脚本仍保留。
- UI ↔ UXP 的自动化与隔离测试已通过相应断言；真实 Photoshop 的回图、候选定位、批量回传和不同版本兼容仍必须按交接文档人工确认，不能仅凭 Node/Electron 结果宣布完成。
- UXP 插件保持明文，只执行 Photoshop 原子动作；AI 请求在 Electron 主进程执行，Key 不经过 UXP。
